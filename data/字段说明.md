# Excel 数据字段说明

本网页通过读取 `data/articles.xlsx` 来渲染古文目录与每一关的内容。
老师只需要在 Excel 中维护数据即可，不必修改代码。

文件包含两个工作表：`articles` 和 `questions`。**请务必保留两个工作表的英文名和首行表头**，
其余的字段值（标题、题目、答案……）均使用中文填写。

## 工作表 1：`articles`（古文目录与基本信息）

每一行对应一篇古文，会显示在目录页的卡片上，点击后进入详情页。

| 列名 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| `id` | 是 | 文章唯一编号，与 `questions` 中的 `articleId` 关联，使用英文/拼音/数字均可 | `fatan` |
| `游戏名称` | 是 | 目录卡片标题、详情页"展示 1"标题 | 古文匠人·魏风伐檀 |
| `适配对象` | 是 | 适用学段或专业 | 职业中学 计算机应用专业 高一学生 |
| `核心课文` | 是 | 对应古文 | 诗经·伐檀（出自《魏风》） |
| `时空定位` | 是 | 时代与地点 | 春秋时期·魏国（今山西南部黄河沿岸） |
| `玩法` | 是 | 玩法概述，目录卡片摘要文本 | 线性八关，每关自学任务 + 1 道检验题 |
| `游戏序` | 是 | 详情页"展示 2"剧情文案 | 你穿越到 2700 年前的黄河之畔…… |
| `视频地址` | 是 | 视频文件地址，可使用相对路径（如 `videos/fatan.mp4`）或网络 URL | videos/fatan.mp4 |
| `总结` | 是 | 详情页"展示 4"总结文案 | 将第八关改为诗歌原本的时空…… |
| `通关奖励` | 否 | 通关后弹出的奖励说明 | 集齐 8 枚"魏风铜章"…… |
| `封面图` | 否 | 目录卡片封面图（相对路径或网络地址）。留空时自动用游戏名称生成纯色封面 | images/fatan.jpg |

## 工作表 2：`questions`（视频节点问题）

每一行表示一道关卡题。视频播放到指定秒数时会暂停弹题，答对继续播放，答错跳回上一节点重看。

| 列名 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| `articleId` | 是 | 关联 `articles.id` | fatan |
| `关卡序号` | 是 | 第几关，从 1 开始的整数 | 1 |
| `关卡名称` | 是 | 例如"听·辨音识韵" | 听（辨音识韵） |
| `视频节点秒数` | 是 | 视频播放到该秒数时暂停弹题（整数，单位：秒） | 30 |
| `学习目标` | 否 | 弹窗中的小提示 | 通过听读，掌握节奏与入声字 |
| `自学任务` | 否 | 弹窗中的任务说明 | 听范读，标记停顿…… |
| `题型` | 是 | 见下表 | single |
| `题目` | 是 | 题干 | 以下哪句朗读停顿正确？ |
| `选项A`,`选项B`,`选项C`,`选项D` | 视题型而定 | 选项内容（不足留空） | 河水/清且涟猗 |
| `正确答案` | 是 | 见下表填写规则 | A |
| `答案解析` | 否 | 答错时弹窗解释 | 标准断句应为…… |
| `重播跳回秒数` | 否 | 答错时视频跳回到的秒数；留空或填 0 表示自动跳回当前节点前 5 秒 | 0 |

### 题型与正确答案填写规则

| 题型 | 含义 | 选项填写 | 正确答案 |
| --- | --- | --- | --- |
| `single` | 单选题 | 选项 A/B/C/D 各填一项 | 字母，如 `A` |
| `judge` | 判断题 | 选项 A、B 留空即可（自动显示"对/错"） | `对` 或 `错` |
| `match` | 连线题 | 选项 A 填左侧条目，选项 B 填右侧条目；条目之间用半角竖线 `\|` 分隔 | 用半角分号 `;` 连接配对，如 `寘=放置;县=悬挂` |
| `sort` | 排序题 | 选项 A 填所有可排序句子，用 `\|` 分隔 | 用半角逗号分隔的正确顺序索引（从 1 开始），如 `2,3,1,4` |

> 提示：连线题/排序题中的分隔符必须使用 **半角** 的 `\|` 和 `;`、`,`，**不要**写成中文符号。

## 视频文件存放位置

- 推荐把视频放到 `videos/` 文件夹，例如 `videos/fatan.mp4`，然后在 `articles.视频地址` 列填写相对路径。
- 也可以填外网视频 URL（需允许跨域）。
- 推荐使用 H.264 编码的 mp4，浏览器原生支持。

## 修改后如何生效

1. 直接在表格软件（Excel / WPS / 在线 Office）中编辑 `data/articles.xlsx` 并保存。
2. 重新刷新浏览器页面即可看到更新；如发布到 Gitee Pages，提交并推送 `articles.xlsx` 即可。
3. **无需修改任何代码**。
